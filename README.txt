# STUDY TIME

간단한 공부 타이머 웹사이트입니다.

## 실행하기
`index.html` 파일을 더블 클릭하면 브라우저에서 바로 열립니다.

## Vercel에 배포하기
1. GitHub에 새 저장소(repository)를 만듭니다.
2. 이 폴더의 `index.html`을 저장소에 업로드합니다.
3. Vercel에 로그인하고 `Add New...` → `Project`를 선택합니다.
4. 방금 만든 GitHub 저장소를 Import합니다.
5. 별도 설정 없이 `Deploy`를 누르면 웹사이트 주소가 만들어집니다.

## 기능
- 집중 25분 / 휴식 5분 전환
- 시작, 일시정지, 초기화
- 집중 시간 및 완료 세션 수 기록
- 브라우저를 닫았다 열어도 기록 유지 (같은 브라우저 기준)
